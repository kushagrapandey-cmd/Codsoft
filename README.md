# Codsoft Frontend Projects

A collection of internship frontend exercises using HTML, CSS and JavaScript.

| Project | Entry point | Implementation |
| --- | --- | --- |
| Calculator | `Calculator/index.html` | Button-driven arithmetic input, clear and delete controls |
| Coffee-shop landing page | `Coffee_shop_Landing_Page/index.html` | Menu, search and cart-panel interactions |
| Personal portfolio | `Portfolio-Kushagra/index.html` | Portfolio layout and presentation |

Open an entry-point HTML file in a browser. The projects are independent and do not require a build step.

The coffee-shop cart is a UI demonstration, with no checkout backend. The calculator evaluates expressions with JavaScript `eval`; it is an exercise rather than a safe parser for untrusted expressions.

For current professional experience and featured projects, see the [engineering portfolio](https://kushagra-portfolio-plum.vercel.app/) and [GitHub profile](https://github.com/kushagrapandey-cmd).
